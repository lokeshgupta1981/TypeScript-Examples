# TypeScript - How to Add Items to Array

Source code for the article [TypeScript - How to Add Items to Array](https://howtodoinjava.com/typescript/typescript-array-add-append-items/).

## Versions

- TypeScript 7.0.2
- Node.js 22 or newer

## Run

```bash
npm install
npm start
```

`npm start` compiles the project and prints the array after each step shown in the article.

## Files

| File | Article section |
|---|---|
| `src/00-quick-reference.ts` | Snippet with every method at the top of the article |
| `src/01-push.ts` | 1. `push()`, including the `RangeError` with a very large spread |
| `src/02-unshift.ts` | 2. `unshift()` |
| `src/03-splice.ts` | 3. `splice()` to insert at an index |
| `src/04-new-array.ts` | 4. Spread, `concat()`, `toSpliced()` and readonly arrays |
| `src/05-typing.ts` | 5. Typed empty arrays, arrays of objects, union element types |
| `src/06-unique.ts` | 6. `includes()` check and `Set` |
| `src/index.ts` | Runs every section in order |

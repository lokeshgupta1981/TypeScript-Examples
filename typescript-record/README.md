# TypeScript Record (with Examples)

Source code for the article [TypeScript Record (with Examples)](https://howtodoinjava.com/typescript/typescript-record/).

## Versions

- TypeScript 7.0.2
- Node.js 22 or newer

## Run

```bash
npm install
npm start
```

# TypeScript / JavaScript Spread Operator (with Examples)

Source code for the article [TypeScript / JavaScript Spread Operator (with Examples)](https://howtodoinjava.com/typescript/spread-operator/).

## Versions

- TypeScript 7.0.2
- Node.js 22 or newer

## Run

```bash
npm install
npm start
```

`npm start` compiles the project with `tsc` and runs `dist/src/index.js`, which prints the values shown in the article's snippet comments.

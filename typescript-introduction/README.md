# Getting Started with TypeScript

Source code for the article [Getting Started with TypeScript](https://howtodoinjava.com/typescript/typescript-introduction/).

## Versions

- TypeScript 7.0.2
- Node.js 22 or newer (22.18 or newer for `npm run hello`, which runs a `.ts` file directly)

## Run

```bash
npm install
npm start          # compile with tsc, then run dist/src/index.js
npm run hello      # run src/hello.ts directly with Node.js type stripping
```

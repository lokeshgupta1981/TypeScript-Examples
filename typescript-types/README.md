# TypeScript Types

Source code for the article [TypeScript Types](https://howtodoinjava.com/typescript/typescript-types/).

## Versions

- TypeScript 7.0.2
- Node.js 22 or newer

## Run

```bash
npm install
npm start
```

`npm start` compiles the project in strict mode and prints the values shown in the article's snippet comments.

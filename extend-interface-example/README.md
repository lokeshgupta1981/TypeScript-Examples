# TypeScript Extend Interface, Merge and Intersection Types

Source code for the article [TypeScript Extend Interface, Merge and Intersection Types](https://howtodoinjava.com/typescript/extend-interface-example/).

## Versions

- TypeScript 7.0.2
- Node.js 22 or newer

## Run

```bash
npm install
npm start
```

`npm start` compiles the project and prints the values shown in the article's snippet comments, one block per section.

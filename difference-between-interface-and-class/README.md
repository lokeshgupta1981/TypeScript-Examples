# TypeScript Interface vs. Class: What's Difference?

Source code for the article [TypeScript Interface vs. Class: What's Difference?](https://howtodoinjava.com/typescript/difference-between-interface-and-class/).

## Versions

- TypeScript 7.0.2
- Node.js 22 or newer

## Run

```bash
npm install
npm start
```

`npm start` compiles the project and prints the values shown in the article's snippet comments. Open the files in `dist/src` after the build to see that the interfaces are removed and the classes remain.

# Difference between let, var and const in JavaScript

Source code for the article [Difference between let, var and const in JavaScript](https://howtodoinjava.com/typescript/var-let-const/).

## Versions

- TypeScript 7.0.2
- Node.js 22 or newer

## Run

```bash
npm install
npm start          # compile the TypeScript snippets and run them
npm run js         # run js/runtime-errors.js (JavaScript runtime behavior)
```

## Files

| File | Article section |

| `src/00-quick-reference.ts` | Quick-reference snippet |
| `src/01-var.ts` | 2. The var Keyword: Function Scope |
| `src/02-let.ts` | 3. The let Keyword: Block Scope |
| `src/03-const.ts` | 4. The const Keyword: No Reassignment |
| `src/04-literal-types.ts` | 5. How const Changes the Inferred Type in TypeScript |
| `src/index.ts` | Runs the sections in order |
| `js/runtime-errors.js` | var hoisting, temporal dead zone, const reassignment and an undeclared variable at runtime |

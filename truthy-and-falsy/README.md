# Truthy and Falsy Expressions

Source code for the article [Truthy and Falsy Expressions](https://howtodoinjava.com/typescript/truthy-and-falsy/).

## Versions

- TypeScript 7.0.2
- Node.js 22 or newer

## Run

```bash
npm install
npm start
```

`npm start` compiles the project in strict mode and prints the values shown in the article's snippet comments.

# TypeScript Function Types

Source code for the article [TypeScript Function Types](https://howtodoinjava.com/typescript/functions-rest-optional-default-params/).

## Versions

- TypeScript 7.0.2
- Node.js 22 or newer

## Run

```bash
npm install
npm start
```

`npm start` compiles the project with `tsc` and runs `dist/src/index.js`, which prints the result of every section.

# TypeScript Array of Objects

Source code for the article [TypeScript Array of Objects](https://howtodoinjava.com/typescript/typescript-array-of-objects/).

## Versions

- TypeScript 7.0.2
- Node.js 22 or newer

## Run

```bash
npm install
npm start
```

## Files

| File | Article section |
|---|---|
| src/person.ts | Shared Person interface and sample data |
| src/00-quick-reference.ts | Cheat sheet at the top of the article |
| src/01-declare.ts | 1. Declaring the Type of an Array of Objects |
| src/02-add-remove-update.ts | 2. Adding, Removing and Changing Objects |
| src/03-find-filter.ts | 3. Finding and Filtering Objects by a Property |
| src/04-sort.ts | 4. Sorting by a Property |
| src/05-transform-group.ts | 5. Extracting, Summing and Grouping Objects |
| src/06-copy-update.ts | 6. Copies, readonly and Updates Without Mutation |
| src/index.ts | Runs all examples in order |

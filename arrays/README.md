# TypeScript Array or List (with Examples)

Source code for the article [TypeScript Array or List (with Examples)](https://howtodoinjava.com/typescript/arrays/).

## Versions

- TypeScript 7.0.2
- Node.js 22 or newer

## Run

```bash
npm install
npm start
```

`npm start` compiles the project and prints the values shown in the comments of each snippet in the article.

## Files

| File | Article section |
|---|---|
| `src/00-quick-reference.ts` | Cheat sheet at the top of the article |
| `src/01-creating-arrays.ts` | 1. Declaring a typed array (`T[]`, `Array<T>`, fixed length, unions, objects, nested arrays) |
| `src/02-reading-elements.ts` | 2. Reading elements by index (`at()`, `length`, destructuring) |
| `src/03-copying-methods.ts` | 4. ES2023 `toSorted()`, `toReversed()`, `toSpliced()`, `with()` and the default sort trap |
| `src/04-looping.ts` | 5. `for...of`, `entries()`, `forEach()`, `for...in` |
| `src/05-copy-merge.ts` | 6. Spread copy, `concat()`, `structuredClone()` |
| `src/06-readonly-arrays.ts` | 7. `readonly`, `ReadonlyArray`, `as const` |
| `src/07-tuples.ts` | 8. Tuple types |
| `src/index.ts` | Runs every section in order |

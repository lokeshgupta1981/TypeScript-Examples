# TypeScript Generic Function, Class and Interface

Source code for the article [TypeScript Generic Function, Class and Interface](https://howtodoinjava.com/typescript/generic-function-class-interface-examples/).

## Versions

- TypeScript 7.0.2
- Node.js 22 or newer

## Run

```bash
npm install
npm start
```

`npm start` compiles the project with `tsc` and runs `dist/src/index.js`, which prints the result of every section.

# Difference between Transpiler and Compiler - TypeScript

Source code for the article [Difference between Transpiler and Compiler - TypeScript](https://howtodoinjava.com/typescript/transpiler-vs-compiler/).

## Versions

- TypeScript 7.0.2
- Node.js 22 or newer (`npm run strip` uses the experimental `stripTypeScriptTypes()` from `node:module`)

## Run

```bash
npm install
npm start               # compile src with tsc and run it
npm run emit:es2024     # compile samples/cart.ts to out/es2024/cart.js
npm run emit:es2015     # compile samples/cart.ts to out/es2015/cart.js (downleveled syntax)
npm run strip           # strip types from one line with Node.js
```

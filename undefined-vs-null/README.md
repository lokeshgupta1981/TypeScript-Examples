# Difference between undefined and null

Source code for the article [Difference between undefined and null](https://howtodoinjava.com/typescript/undefined-vs-null/).

## Versions

- TypeScript 7.0.2
- Node.js 22 or newer

## Run

```bash
npm install
npm start
```

`npm start` compiles the project in strict mode and prints the values shown in the article's snippet comments.

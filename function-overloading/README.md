# TypeScript Function or Method Overloading

Source code for the article [TypeScript Function or Method Overloading](https://howtodoinjava.com/typescript/function-overloading/).

## Versions

- TypeScript 7.0.2
- Node.js 22 or newer

## Run

```bash
npm install
npm start
```

`npm start` compiles the project with `tsc` and runs `dist/src/index.js`, which prints the result of every section.

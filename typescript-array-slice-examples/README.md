# TypeScript Array slice() with Examples

Source code for the article [TypeScript Array slice() with Examples](https://howtodoinjava.com/typescript/typescript-array-slice-examples/).

## Versions

- TypeScript 7.0.2
- Node.js 22 or newer

## Run

```bash
npm install
npm start
```

`npm start` compiles the project and prints the result of every `slice()` call shown in the article.

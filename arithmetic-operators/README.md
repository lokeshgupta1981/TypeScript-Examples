# TypeScript Arithmetic Operators

Source code for the article [TypeScript Arithmetic Operators](https://howtodoinjava.com/typescript/arithmetic-operators/).

## Versions

- TypeScript 7.0.2
- Node.js 22 or newer

## Run

```bash
npm install
npm start
```

`npm start` compiles the project with `tsc` and runs `dist/src/index.js`, which prints the values shown in the article's snippet comments.
